# Cruis'n World para Android

Projeto Android dedicado para executar sua própria ROM de Nintendo 64, com controles touch e gamepad físico por meio de emulação integrada.

> ROM comercial não incluída: este repositório é público. A ROM é selecionada na primeira execução do aplicativo.

A compilação será configurada com GitHub Actions e exportará o APK como artefato na aba **Actions**.

O projeto utiliza o frontend de código aberto Ludere e um núcleo libretro de Nintendo 64. A compilação e o jogo precisam ser testados em aparelho real.
